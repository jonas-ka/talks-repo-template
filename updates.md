# Research updates

Dated log of new results since the last talk on a topic. When a talk is generated, every
entry dated after the most recent talk on the same topics is proposed as a new or revised
block.

Format: one entry per result, newest first.

```
## 2026-01-01 — <one-line headline>
topics: [topic-a, topic-b]
Short description of the result, what figure or number changed, and which block it
affects. Link the catalog id of the new figure.
```
