# Example experiment

*What a project page holds: the project in a few paragraphs, so that someone new can start.
It is living text: it changes when the facts change, and every change is in git.*

**Goal.** Measure the transmission of the example beamline as a function of the source
settings, and keep the best settings so they can be restored.

**People.** A. Author (ion source), B. Builder (beamline), C. Chair (lead).

**Where things live.** Raw data: the DAQ archive and the Drive folder
`Example/Data/Transmission`. Analysis code: the project repository. Figures: the Drive
figure library. Settings: EPICS snapshots stored with the entries (`--epics source-tune`).

**Apparatus.** [[wiki:apparatus/source]], [[wiki:apparatus/beamline]].

**Background reading.** [@Author2019] for the method, [@Writer2001] for ion traps in general.
